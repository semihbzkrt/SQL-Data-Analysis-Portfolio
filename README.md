# 📊 SQL Data Analysis & Business Intelligence Portfolio

## 📌 Proje Hakkında
Bu proje, e-ticaret ve lojistik ekosistemini simüle eden kapsamlı bir rönesans (sıfırdan inşa) veri tabanı projesidir. Veri manipülasyonundan (DML/DDL) başlayarak, ileri düzey analitik raporlamaya, küme işlemlerine ve programlanabilir SQL (T-SQL / MySQL) mimarisine kadar uzanan 7 günlük yoğun bir iş senaryosu maratonunu içerir. 

Yönetim Bilişim Sistemleri (YBS) 4. sınıf öğrencisi olarak, veri analitiği, iş analistliği ve veritabanı yönetimi alanlarındaki teknik yetkinliklerimi sergilemek amacıyla, tamamen gerçek dünya iş problemlerinden (Business Cases) yola çıkılarak tasarlanmıştır.

## 🛠️ Kullanılan Teknolojiler ve Altyapı
* **Veritabanı Motorları:** MySQL / MariaDB (DB Fiddle üzerinden) & MS SQL Server (T-SQL Kavramları)
* **Araçlar:** DB Fiddle (Sorgu Optimizasyonu ve Test), GitHub (Versiyon Kontrolü)
* **Kapsam:** 3 Ana Tablo (`musteriler`, `kapsamli_satislar`, `kargo_sirketleri`) ve 26 Farklı İş Problemi.

## 🧠 Kazanılan Teknik Yetkinlikler
Bu portfolyo çalışması kapsamında aşağıdaki SQL yetkinlikleri uygulamalı olarak kanıtlanmıştır:

* **Veritabanı Tasarımı (DDL/DML):** Primary Key (PK) ve Foreign Key (FK) mantığıyla ilişkisel tablolar oluşturma (`CREATE`), veri manipülasyonu (`INSERT`, `UPDATE`, `DELETE`).
* **Veri Çekme ve Filtreleme:** İleri düzey `WHERE` operatörleri (`LIKE`, `IN`, `BETWEEN`, `AND/OR`).
* **İlişkisel Veri Analizi (JOINs):** Farklı tablolardaki verileri iş kurallarına göre birleştirme (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`).
* **Kümeleme ve Dikey Birleştirme:** Farklı veri setlerini kesiştirme, ayıklama ve tekilleştirme (`INTERSECT`, `EXCEPT`, `UNION`, `UNION ALL`).
* **Alt Sorgular (Subqueries):** Sabit filtreler yerine dinamik olarak sistemden beslenen iç içe sorgular yazma.
* **Akış Kontrolü ve Segmentasyon:** `CASE WHEN` koşullu ifadeleriyle dinamik ürün/müşteri segmentasyonu.
* **Değişken Yönetimi ve Döngüler:** `DECLARE` / `SET` komutlarıyla parametrik rapor şablonları oluşturma, `WITH RECURSIVE` ile analitik döngü (Loop) ve sayaç tasarımı.
